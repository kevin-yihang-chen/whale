\section{Status}
This is an executable-study scaffold, not a completed experimental supplement.
Source code, data identities, raw answers, candidate failures, native training
receipts and GPU/API costs must be linked before a result is populated.
\section{Shared Scoring}
Answer extraction is host-owned. Invalid ground truth is a data error; an
incorrect or malformed model answer is an unsuccessful trajectory. Pair scores
require complete identity-matched predictions on both sides. No invalid or
missing sample is silently replaced with a zero or removed from the denominator.
\section{Reproducibility}
All seeds and condition names are preregistered. The same source family cannot
cross data roles. Every real run retains its configuration, source snapshot,
model and processor identities, decoder settings, raw responses, and terminal
Slurm allocation record. Shared-prefix computations are identified explicitly.
The Adam-reset restoration caveat is shared by every trained branch.
